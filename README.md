# Korede Folarin Portfolio

Static, responsive portfolio site ready for free hosting.

## Files
- `index.html` — homepage
- `styles.css` — visual system
- `script.js` — smooth navigation
- Three root-level flagship case-study HTML pages

## Before publishing
Replace the `#` placeholder links with:
- LinkedIn URL
- GitHub profile URL
- Each project's live deployment URL
- Each project's GitHub repository URL

Also confirm the email address in `index.html`.

## Free deployment
You can host this repository with GitHub Pages and connect `koredefolarin.com` as the custom domain.
